# IBM Bob Session Exports

This folder documents IBM Bob's role as a development and review tool for LoadGuard. The files are historical session summaries, not required runtime inputs.

- [`planning-session.md`](planning-session.md) — Bob's contribution to solution design and the
  multi-agent architecture.
- [`coding-session.md`](coding-session.md) — Bob's contribution to implementation, tests, and
  debugging.

The custom mode used to drive these sessions is defined in [`.bob/custom_modes.yaml`](../.bob/custom_modes.yaml). The MCP integration is documented in [`mcp_server/README.md`](../mcp_server/README.md).
