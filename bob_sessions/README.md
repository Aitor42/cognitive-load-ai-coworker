# IBM Bob Session Exports

This folder documents IBM Bob's role as the primary development tool for LoadGuard,
as required by the IBM AI Builders Challenge submission guidelines.

- [`planning-session.md`](planning-session.md) — Bob's contribution to solution design and the
  multi-agent architecture.
- [`coding-session.md`](coding-session.md) — Bob's contribution to implementation, tests, and
  debugging.

The custom mode used to drive these sessions is defined in [`.bob/custom_modes.yaml`](../.bob/custom_modes.yaml).
